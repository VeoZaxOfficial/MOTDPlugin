# MOTDPlugin

A dynamic MOTD plugin for VeoZaxAPI / PocketMine-MP servers: PM2 (API 2.0.0)

## ✨ Features
- Dynamic server MOTD
- Uptime display
- Configurable messages

## 📦 Installation
1. Download the plugin: [⬇ Download MOTDPlugin]([YOUR_DOWNLOAD_LINK_HERE](https://www.mediafire.com/file/68q296o5kdpfq3h/MOTDPlugin_v1.0.0.phar/file))
2. Upload to `/plugins`
3. Restart server
